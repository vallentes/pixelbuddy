Questions

 

Is it really free?

Yes. No trial, no ads, no subscriptions, no tracking. If it makes you smile you can buy me a coffee, but you never have to.

Windows says "Windows protected your PC"

The installer isn't code-signed yet (certificates are expensive). Click More info → Run anyway. The source is public on GitHub.

How do I open it on a Mac?

Drag PixelBuddy to Applications, then right-click it and choose Open the first time. On macOS 15+, use System Settings → Privacy & Security → Open Anyway.

Does it slow down my computer?

No. Pets pause during fullscreen games and videos, slow down while you're away, and there's a performance mode for older laptops.

Does it update itself?

Yes, from version 1.2 on. It checks for new versions and asks before installing.

Is it open source?

The code is public to read on GitHub, but it's free software, not open source: all rights are reserved.
